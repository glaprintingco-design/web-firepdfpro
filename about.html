About FirePDF Pro

Built by contractors, for contractors.

Why We Built This

Anyone who has worked as a fire alarm contractor in New York City knows the paperwork burden. Before a single wire is run, you're filling out TM-1 applications, A-433 certifications, B-45 inspection requests — each requiring building data you have to look up manually, contractor details you have to type in from scratch, and device lists you have to format by hand.

FirePDF Pro was built to eliminate that friction. Enter a BIN, add your devices, and walk away with a complete, submission-ready package in seconds. What used to take 45 minutes now takes 2.

Who It's For

FirePDF Pro is designed specifically for NYC-licensed fire alarm contractors — companies and individuals who regularly file with FDNY and need a faster, more reliable way to produce accurate documentation.

Whether you're running 3 jobs a month or 300, the tool adapts. The Free plan lets you test it with real jobs. The Pro plan removes all limits so you can use it on every project.

How It Works

We pull publicly available building data from the NYC Department of Buildings API using the Building Identification Number (BIN) you enter. That data — address, block, lot, borough, ownership — gets merged with your company profile and the devices you specify to produce properly formatted PDF documents.

No data is sent to any third party other than the NYC DOB API (which only receives the BIN number). Your profile and project history are stored securely in a private database with row-level access controls.
